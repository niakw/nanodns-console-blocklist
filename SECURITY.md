# Security policy

## Support

This is a community-maintained **DNS configuration**, not a security appliance. There is **no guarantee** that firmware updates, account communication, telemetry, game updates, direct IP traffic or third-party endpoints are fully blocked.

The current shipped configuration targets **nanoDNS v0.4** and was observed loading on **PS5 firmware 13.60**. Other versions/consoles are community targets but not hardware-certified.

## Reporting

For an exploitable security issue that would put users at risk, use GitHub's **Report a vulnerability** feature (repository → Security → Advisories) if available. Otherwise open an issue containing only non-sensitive reproduction details and request a private channel from the maintainer.

For a missing blocked hostname or false positive, open a normal GitHub issue with the hostname, a redacted log sample and a source link. Do not publish private account information or credentials.

## Disclosure expectations

Please avoid posting instructions that would facilitate harming others or exposing private data. Project maintainers review reports on a best-effort basis; no response-time or patch-time guarantee is provided.
